# MFSYS Security Policy

Never commit secrets, credentials, tokens or production environment files.

Production requirements:
- MFA/SSO for administrators
- Server-side RBAC
- WAF and distributed rate limiting
- Audit logging
- Dependency and secret scanning
- Automated CI checks
- Backups and restore testing
- Security assessment before production launch

Report suspected vulnerabilities privately to the MFSYS security/technology team.
